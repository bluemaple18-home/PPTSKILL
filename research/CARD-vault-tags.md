# Founder Vault 與標籤盤點

- 目標：從知識庫、Founder Vault、可重建 vault/tag 索引找出既有簡報 SOP、設計原則、視覺偏好與相關專案紀錄。
- 範圍：唯讀讀取 vault 的 README／memory summary 後，以「簡報、投影片、presentation、slide、deck、HTML、storytelling、visual」及既有 tag 關聯限域搜尋。
- 禁區：不改 vault、不建立新 note、不讀 credentials／客戶機密、不把原始搜尋結果直接視為 canonical。
- 驗收：回傳命中文件與段落位置，彙整 5–15 個可復用模式，標示來源、重複度、時效性及是否適合公版工作流。
- 停損：索引或 vault 不存在時列出缺口；不要建立替代知識庫。
