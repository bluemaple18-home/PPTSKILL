# 投影片文案：去 AI 味的專屬規則（繁中／台灣）

配合 `writing-skills/` 裡的通用去 AI 味 skill 使用。**先看這一頁，再用那些工具。**

---

## 一、為什麼通用的去 AI 味規則不能直接套到投影片

`stop-slop`、`speak-human-tw`、`shuorenhua-zh-tw` 都是為**散文**設計的。它們的評分看
節奏、句長變化、密度、信任感——這些指標建立在「一段有好幾個句子」的前提上。

投影片一頁通常只有 10–40 個字。直接套會出兩種錯：

| 通用規則 | 套到投影片會怎樣 |
|---------|----------------|
| 罰「短句轟炸」「句長一致」 | 投影片本來就該短、該齊，會被誤判 |
| 罰「名詞片語沒有動詞」 | 標題本來就常是名詞片語 |
| 獎勵「句子節奏多變」 | 三欄卡片刻意平行，是設計不是缺陷 |
| 對成品 HTML 執行 | 會改到 class 名、CSS 值、註解 |

**執行時機**：在「大綱與逐頁文案」階段跑，不要對已經寫成 HTML 的成品跑。

## 二、投影片專屬的八種 AI 味

一般文章的 AI 味長在句子裡；投影片的 AI 味長在**結構與主張**上。

1. **強迫三點式**
   每頁都三張並列卡片，內容硬湊成三個。真的只有兩點就寫兩點。

2. **標題是題目，不是結論**
   ✗ 「市場分析」「產品優勢」「未來展望」
   ✓ 「大盤成長 12%，但我們的客單價掉了 8%」
   標題應該是這頁的 takeaway，觀眾只看標題也能拼出故事線。

3. **抽象名詞當內容**
   賦能、打造、深度整合、全方位、生態系、閉環——拿掉之後如果句子沒有損失，
   那句話本來就沒有內容。問：具體要做什麼動作？誰做？做完會怎樣？

4. **形容詞當論據**
   ✗ 「顯著提升成效」　✓ 「CTR 從 0.8% 到 1.3%」
   沒有數字就不要用程度副詞。沒數字時誠實寫「還在驗證」。

5. **並列強迫症**
   每個 bullet 一樣長、一樣句型、一樣詞性。真實的重點本來就不等長。

6. **句型套殼**
   「不僅⋯更⋯」「從⋯到⋯」「在⋯的今天」「隨著⋯的到來」。
   這些殼可以套進任何內容，所以套進去也等於沒說。

7. **空的過渡頁與結束頁**
   ✗ 「接下來，讓我們看看⋯」「謝謝聆聽，讓我們一起創造未來」
   ✓ 結束頁放：下一步行動、一個決策請求、或一句真的相關的引文。

8. **名詞化**
   「進行優化」→「調快」；「做出貢獻」→「多帶進 200 個註冊」。
   中文的 AI 味很大一部分就是把動詞包成「進行／做出／實現＋名詞」。

## 三、正向規則

- **標題寫結論**（takeaway title），不寫類別
- **一頁一個主張**，撐不滿就拆頁或合頁，不要填充
- **有數字給數字**，沒有就不要用程度副詞
- **動詞優先**，拆掉名詞化
- **欄數服從內容**，兩點就兩欄
- **口語校對**：把整頁念出來，念不順的多半是寫給眼睛看、不是寫給人聽的

## 四、台灣用語（AdTech 特別注意）

**一般要改**

軟件→軟體、視頻→影片、信息→資訊、質量→品質、項目→專案、網絡→網路、
通過→透過、屏幕→螢幕、內存→記憶體、默認→預設、激活→啟用、上線→上架（依脈絡）

**不要盲改的產業詞**

台灣數位廣告業界日常就這樣講，改掉反而不像業內人寫的：

- **數據**——統計脈絡通用（第一方數據、數據分析）。`shuorenhua` 的表已標 ⚠，別無腦換成「資料」
- **用戶**——行銷脈絡的「用戶數」「用戶輪廓」常見；正式文件才回到「使用者」
- **投放、流量、素材、曝光、成效、版位、出價**——都是台灣廣告業標準用語，不是中國用語

判準：這個詞在台灣的同業簡報裡會出現嗎？會，就留著。

**標點**：半形改全形（，。：；？！），數字與英文維持半形。

## 五、一頁檢查表

寫完逐頁文案後，逐項問：

- [ ] 每頁標題單獨讀，能不能拼出完整故事線？
- [ ] 有沒有哪一頁只是因為「要有三點」而存在？
- [ ] 抽象名詞（賦能／打造／整合／全方位）出現幾次？能不能全部換成動作？
- [ ] 每個程度副詞後面有沒有數字撐著？
- [ ] 結束頁有沒有給出下一步，而不是客套？
- [ ] 中國用語掃過一遍，但產業詞有沒有被誤殺？
- [ ] 念出來順不順？
