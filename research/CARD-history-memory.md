# 簡報歷史對話與記憶盤點

- 目標：找出 Matt 過去與 AI 討論、製作或驗收 HTML 簡報時反覆使用的流程與判斷。
- 範圍：唯讀查詢 Antigravity/global memory、可用的本機對話索引與 handoff；搜尋「簡報、投影片、presentation、slide、HTML deck、封面、視覺驗收、MD HTML Viewer」及相近詞。
- 禁區：不寫入記憶、不修改任何檔案、不把單次偏好升格為公版規則、不讀 credentials 或客戶敏感內容。
- 驗收：回傳 5–15 個重複套路；每項附來源類型、可定位路徑／記錄 ID 或查詢證據、信心與「公版候選／個人偏好／單次情境」分類。
- 停損：若兩種查詢方式均無結果，明確列出查過的位置與關鍵字後停止，不猜測。
