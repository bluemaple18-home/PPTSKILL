# Public Demo Dark Company Style Pack

此目錄是公開版使用的 synthetic Company Style fixture。所有圖片都由程式產生，不包含公司 logo、客戶素材、原始 PPTX、原始文案、備註或本機來源路徑。

- `company-style-pack.json`：機器可讀 Style Pack。
- `company-style-calibration.md`：公開 fixture 的量測規則與限制。
- `assets/`：可公開再散布的 synthetic 圖像。

此 fixture 只保留 Company Style 工作流與 layout contract 的可重現形狀，不代表任何私人品牌的視覺資產。
