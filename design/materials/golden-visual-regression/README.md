# Golden Visual Regression

這是 Owner 明確核准之 PPTSKILL 輸出的長期人工比較集，不是 pixel-matching snapshot suite，也不取代 deterministic tests 或 browser geometry gate。

收錄條件：

- 必須有 Owner 明確 `PASS`。
- 必須保留原始 evidence 與 receipt 路徑。
- 比較 hierarchy、composition tension、negative space、typography maturity、visual-anchor quality、semantic relevance、visual weight、palette-area balance、template smell 與 overall presentation-slide maturity。
- motion/effect candidate 在 Owner motion verdict 前不得標記為 Golden。

目前收錄項目由 `manifest.json` 管理。
